# Artwork update — Launcher 1.2

Built-in image_gen was used to redraw both game covers using screenshots from the actual Unity projects as references.

PTVCar: assets/ptvcar-v2.png. References: PTVCar/Assets/Screenshots/Window-Home-1024.png and RaceGrid.png. Prompt: friendly compact cartoon cars with large windshield eyes, yellow and turquoise stock cars and a dark vintage car, racing on a sunny pine-forest circuit; stylized 3D game cover with no HUD or captions.

PTVvs: assets/ptvvs.png. References: SuMo project screenshots TikTokViewerArena.png and TimedRoundTeamPodium.png. Prompt: angular low-poly armored gladiators with brown bronze armor, helmets and chunky boots, fighting on grass in a wooden-palisade village arena; red and blue energy accents, preserve actual character proportions, no sumo wrestlers, HUD or text.

Roblox covers are the official experience icons for the four linked maps. Controller and tilted Roblox square are native WPF vector shapes, matching the supplied launcher reference. Vertical scrollbars are hidden; mouse-wheel scrolling remains available.

The internal game ID remains sumo to preserve previous installed game directories and favorites; display name, executable, cover and manifest are now PTVvs. Updates at equal version numbers detect renamed executables and, for new installs, changed ZIP hashes.

## Paint World — Launcher 1.5.0

assets/paintworld-wide.png is an original image_gen cover, derived from a camera capture of the actual paint gun project (CyanCourtyard scene). The white-gray walled courtyard, gabled buildings, arched gate, planters, low-poly cyan/orange/white paint blaster and cyan-versus-red paint gameplay come from the real game. The cover adds comic PAINT WORLD lettering and illustrated paint splashes. No player account text is included in the cover.


PTVBoat: assets/ptvboat.png was generated with image_gen from a live close-up of PTVBoat_Ocean in the PTVBoat Unity project. It preserves the angular white-gray patrol ship, teal waterline, dark stern helipad and red-white fittings, with tropical ocean islands. Landscape composition fits the four-game row.
# PTVRunner cover (2026-10-23)

`assets/ptvrunner.jpg` was generated with the built-in imagegen tool using actual PTVRunner Studio screenshots as visual references: the waterfront numbered starting grid, navy/cyan/gold barriers, cheering crowd and forest island. It is illustrated promotional art, not an unaltered gameplay screenshot. Title: PTVRunner.

Prompt: 16:9 stylized 3D promotional cover grounded in the actual map; blocky runners racing toward camera on numbered asphalt grid, turquoise ocean, cheering crowd, cyan/gold barriers, golden lightning on leading runner; bold white/cyan PTVRunner title; no settings UI or Studio chrome.
# Gold NEW ribbon (2026-10-23)

`assets/new-gold.png` is a transparent PNG drawn with built-in imagegen, selected option 2. Prompt: standalone diagonal gold corner ribbon, exact bold black NEW, white/gold bevel and restrained glow, folded ends, transparent outside; no game scene. Original retained in workspace outputs/PTVRunner/NEW-designs/new-gold-original.png. Launcher renders this image separately at the top left of the PTVRunner card.
# Acorn Rush cover (2026-10-28)

`assets/ptvegg.png` (1280×720) is a real render from the PTVegg Unity project, not generated art: a low camera beside the squirrel player in the acorn meadow (PTVegg_Map) while the in-game gift cutscene rains acorns from the sky. Only colour grading, a vignette, the game's own wooden title plate (fr_title_header) with the in-game title ACORN RUSH and a "SQUIRREL ACORN HUNT • TikTok LIVE" ribbon were added. The title sits inside the centre 70% so it survives the card crop.
