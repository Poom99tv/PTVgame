Zombie Rush 1.0.2

New pranks
- Jalapeño (1 per gift): a red warning stripe marks the zombie's lane, the pepper puffs up and bursts into a lane-long line of fire. A burnt zombie crumbles into charcoal powder from the feet up, its head drops onto the ash heap, then it rewinds back to life at the start.
- Cherry Bomb (2 per gift, listed before the Jalapeño): a red danger circle appears, the cherries swell and explode; a zombie inside the circle is blasted back 3 boxes.

Changes
- New knock-back wind effect: streaks always run along the length of the lawn.
- Default gift setup updated to the latest in-game settings (all 14 skills). Gift settings saved by older builds are replaced once by this setup.
- HUD, start menu and settings fit 8 prank tiles. Test keys 1-8 follow the on-screen order.

Windows x64: extract the whole ZIP and open ZombieRush/ZombieRush.exe. TikTokBridge with its Node.js runtime is included.
